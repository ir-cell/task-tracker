# Учёт задач команды разработки

Программа для учёта задач небольшой команды разработки: исполнитель, приоритет, этап, срок, фильтрация и сводка.

## Возможности

- Добавление, изменение и удаление задач
- Поля: название, исполнитель, приоритет, этап, срок, статус, описание
- Просмотр всех задач и только просроченных
- Фильтрация по исполнителю, приоритету, этапу, статусу
- Поиск по названию
- Сводка: задачи по статусам, нагрузка исполнителей, просроченные
- Сохранение данных между запусками (JSON-файл)

## Технологии

- Python 3
- JSON (хранение данных)
- unittest (тесты)

## Структура проекта

- `docs/` — исследование, требования, проектирование, прототипы
- `src/` — исходный код
  - `models.py` — класс Task
  - `storage.py` — класс TaskStorage
  - `main.py` — запуск и меню
- `tests/` — тесты (15 штук)
- `README.md` — этот файл
- `.gitignore` — исключения Git

## Установка и запуск

Требуется Python 3.10 или новее.

1. Клонировать репозиторий:

    git clone https://github.com/ir-cell/task-tracker.git
    cd task-tracker

2. Запустить программу:

    python -m src.main

Программа откроет меню:

1. Добавить задачу
2. Показать все задачи
3. Показать просроченные задачи
4. Показать сводку
5. Фильтровать задачи
6. Найти задачу по названию
7. Изменить задачу
8. Удалить задачу
0. Выход

## Запуск тестов

    python -m unittest discover tests

Ожидаемый результат: 15 тестов, OK.

## Хранение данных

Задачи сохраняются в файл `tasks.json` в корне проекта. Файл создаётся автоматически при первом добавлении задачи.
