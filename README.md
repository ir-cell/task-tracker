# Учёт задач команды разработки

Программа для учёта задач небольшой команды разработки: исполнитель, приоритет, этап, срок, фильтрация и сводка.

## Возможности

- Добавление, изменение и удаление задач
- Поля: название, исполнитель, приоритет, этап, срок, статус
- Фильтрация по исполнителю, приоритету, этапу, статусу
- Поиск по названию
- Сводка: задачи по статусам, просроченные, нагрузка исполнителей
- Сохранение данных между запусками

## Технологии

- Python 3
- Tkinter (интерфейс)
- JSON (хранение данных)
